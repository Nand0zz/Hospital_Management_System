# 🏥 Online Hospital Management System

A Java-based console application to digitize hospital operations. This project offers secure access for patients and doctors to manage personal records, appointments, and scheduling, using a SQL database and JDBC. The system is built with modular OOP principles and ensures validation via custom exceptions.

---

## 📌 Problem Statement

In today's fast-paced and digital-first world, managing hospital operations through traditional manual systems leads to inefficiency, human error, and data loss. Patients face difficulties in booking appointments, while doctors lack centralized access to their schedules. There's an urgent need for an integrated platform that connects patients and doctors in a streamlined, digital way.

---

## 💡 Solution / Proposed / Developed

The project provides a console-based Hospital Management System that allows patients to book appointments, manage profiles, and consult doctors online/offline. Doctors can register, view their appointments, and update availability. Built using Java and JDBC, it integrates with a MySQL backend and uses custom exceptions for input validation.

---

## 🧬 Uniqueness and Distinctive Features

- Custom exception handling for strong input validation (name, age, email, phone, time).
- Separate modules for patients and doctors with tailored menus.
- Online and offline appointment slot options.
- Secure authentication and password management.
- JDBC-based database interaction for data persistence.
- Console UI that’s easy to navigate for non-technical users.

---

## 🔍 How It's Different From Similar Products

Unlike existing web-based systems, this project provides a lightweight offline-first system that runs on any machine with Java and SQL. Its focus on exception handling, clear modular design, and role-based access ensures better structure, security, and extensibility. It's an ideal prototype for future GUI or mobile extensions.

---

## 🚀 Features

- 👤 **Role Selection**: Patient / Doctor login flows
- 🔐 **Authentication**: Sign-up, login, forgot password
- 🧑‍⚕️ **Patient Module**:
  - Add/View/Update/Delete personal details
  - Book/View/Update/Delete appointments
- 👨‍⚕️ **Doctor Module**:
  - Add/View/Update/Delete personal details
  - View appointments based on symptoms
- 📅 **Appointment Handling**:
  - Online/Offline consultation type
  - Time slot selection
- ❗ **Custom Exceptions**:
  - Validates name, age, email, phone number, date, and time format
